## 提取和使用说明

- 页码采用 PDF 文件顺序，不一定与说明书印刷页码相同。
- 冰箱和门锁优先保留原文字层，另提供整页 OCR 补充稿，便于查找截图中的文字。补充稿会与正文重复。
- 洗衣机、烘干机、空调面板的主要正文为图片，采用中文 OCR。
- 每一页均已进入提取流程，但并不表示每个字都准确识别。OCR 可能出现错字、漏字、符号误识别和阅读顺序问题，尚未逐字人工校对。
- 图示位置、操作图标及跨行跨列表格，纯文字无法完整保留。安装、维修、安全警告、操作步骤和参数必须对照原 PDF。
- 原始说明书由用户提供，版权归原权利人所有。本资料库用于说明书文字检索，不改变原文件的版权归属，也不额外授予转载或再分发权利。
- 不记录家庭实际开锁密码、账号密码、Wi-Fi 密码、身份证件或其他个人私密资料。手册中的默认密码仅是厂商通用说明。

## 文件结构

- text/：按页组织的全文提取稿。
- ocr-supplement/：有文字层文件的整页 OCR 补充稿。
- sources.json：原文件名称、页数和 SHA-256 校验值。

原 PDF 不包含在本项目中，请保留原件用于核对。
