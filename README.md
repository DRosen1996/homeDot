## 2026-11-08校订范围

- 136页均实际逐页查看原图，并对照可读正文、警告、数字、表格及图中文字完成一轮校订，不是仅重新运行OCR。
- 修复多栏串序、乱码和漏句；补回洗衣机故障排除/代码表、冰箱参数表和环保表、门锁图示编号等。
- 本稿是可检索的逐页文字，不是原版排版复刻。按键图形、箭头、结构图位置、装饰微字和部分截图细字未全部文字化，不保证每个字零误差，也未做实机操作验证。每份核对记录列有具体覆盖和限制。
- 原件本身缺失的内容没有猜补：烘干机网页打印PDF缺故障代码表、有害物质表体及部分图示；洗衣机部分显示字符未呈现。具体位置已在文字及核对记录标注。
- 厂商原文疑似笔误保留并注明；为便于阅读所加说明使用方括号或明确的校订注。
- 安装、维修、安全警告、操作步骤、按键图标和参数仍应对照原PDF。文字校订不替代厂商指导。

## 文件结构

- text/：按PDF页组织的校订文字。
- originals/：用户提供的原PDF备份，冰箱原件封装于ZIP内。
- review/：逐份核对范围、主要修正、原件缺项和保留问题。
- ocr-supplement/：原补充稿入口，现指向统一校订正文，避免继续检索到过时OCR。
- sources.json：来源、页数、SHA-256、备份路径及校订状态。
